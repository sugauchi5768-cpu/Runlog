# ランログ（RunLog）

GPSでランニングの距離とルートを記録し、1kmラップ・日別距離・実力の推移を管理するスマホ用Webアプリです。
ホーム画面に追加すると、普通のアプリと同じように使えます（iPhone / Android 対応）。

## 主な機能

- **計測**：GPSで現在地を測位し、走行距離・タイム・平均ペース・現在ペースを表示。ルートを地図に描画
- **1kmラップ**：1kmごとのラップを自動記録（最速ラップを色分け表示）
- **音声案内**：500mごと（または1kmごと）に距離とキロあたりペースを読み上げ
- **履歴**：日別の合計距離、各ランの詳細（ルート地図・ラップ表）
- **実力の推移**：直近30日の平均ペースを前30日と比較、ベスト1km・ベスト5km・最長距離、ペース推移／日別距離／月間距離のグラフ
- **手動記録**：トレッドミルなどGPSを使わないランも追加可能
- **バックアップ**：記録をJSONファイルで書き出し・読み込み

## ファイル構成

```
runlog/
├─ index.html              アプリ本体
├─ manifest.webmanifest    ホーム画面追加用の設定
├─ sw.js                   オフライン起動用
├─ icons/                  アプリアイコン
└─ vendor/                 地図（Leaflet）・グラフ（Chart.js）ライブラリ
```

## 公開手順（GitHub Pages）

位置情報は `https://` のURLでしか使えないため、GitHub Pages などで公開して使います。

1. GitHubで新しいリポジトリを作成（例：`runlog`、Public）
2. 「Add file」→「Upload files」で、このフォルダの**中身すべて**（index.html・manifest.webmanifest・sw.js・icons・vendor）をアップロードして「Commit changes」
3. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして「Save」
4. 1〜2分後に表示される `https://ユーザー名.github.io/runlog/` が公開URLです

## iPhoneでの使い方

1. 公開URLを **Safari** で開く
2. 共有ボタン →「ホーム画面に追加」
3. 初回起動時の位置情報の確認で「許可」を選ぶ

### 位置情報が使えないとき

1. 設定 → プライバシーとセキュリティ → 位置情報サービス → オン
2. 同じ画面の「Safari Webサイト」→「このAppの使用中のみ許可」、「正確な位置情報」オン
3. Safariのアドレスバー左の「ぁあ」→ Webサイトの設定 → 位置情報 →「許可」

## 使うときの注意

- **計測中は画面を点けたまま、アプリを表示しておいてください。** 画面ロックや他アプリへの切り替えでGPSが止まります（画面の自動消灯は計測中オフになります）。
- GPS精度の表示が緑〜黄になってからスタートすると正確に測れます。高い建物の間やトンネルでは誤差が出ます。
- 記録はスマホのブラウザ内に保存されます。Safariの履歴・データを消去すると記録も消えるため、ときどき「実力」タブからバックアップを書き出してください。
- 地図はインターネット接続時に表示されます（地図がなくても距離の計測は可能です）。

## 更新するとき

index.html などを差し替えたら、`sw.js` の `CACHE = 'runlog-v1.0.0'` の番号を上げてからアップロードすると、利用者の端末に新しい版が確実に反映されます。
